# 🚀 Featured Projects

<div align="center">

### 🚗 CarDamage AI
**Vehicle Damage Detection & Severity Scoring**

</div>

Built a YOLOv8-powered application for detecting vehicle damage from **images and videos**, covering six damage categories:

`Scratch` `Dent` `Crack` `Flat Tyre` `Broken Part` `Shattered Glass`

A custom **0–10 weighted severity score** combines class confidence values to produce:

`LOW` → `MEDIUM` → `HIGH`

**Stack:** `Python` `YOLOv8` `Ultralytics` `OpenCV` `Streamlit` `Roboflow`

---

<div align="center">

### 🎭 MoodLens
**Real-Time Facial Emotion Recognition + Spotify**

</div>

A real-time computer vision application capable of recognizing **7 facial emotions** at approximately **30 FPS**, with live bounding boxes and confidence scores.

The system integrates the Spotify Web API to fetch mood-matched playlists based on the detected dominant emotion.

**Stack:** `Python` `FER` `CNN` `FER-2013` `OpenCV` `Streamlit` `Spotify API`

---

<div align="center">

### 🛡️ Sentinel-X1
**Network Intrusion Detection & Classification**

</div>

A multi-class network traffic classifier trained on the **CICIDS-2017** dataset, covering attacks such as DDoS, PortScan, BruteForce, Botnet, and Web Attacks.

Implemented dimensionality reduction, feature selection, context-aware feature imputation, model comparison, REST endpoints, and an interactive attack visualization interface.

**Stack:** `Python` `LightGBM` `Random Forest` `PCA` `SelectKBest` `Flask` `scikit-learn`

---

<div align="center">

### 🤖 BugLie
**Offline AI Desktop Assistant**

</div>

An **offline-first AI productivity assistant** powered by a local LLM, with smart intent routing for conversations, file-system operations, and application launching.

The project also includes speech-to-text, WhatsApp automation, prayer-time calculations, recursive drive indexing, and a gamified quiz engine.

**Stack:** `Node.js` `Electron` `Ollama` `Python` `WebRTC` `WhatsApp-Web.js`

---

<div align="center">

### 📚 RAG Document Q&A
**Full Retrieval-Augmented Generation Pipeline**

</div>

A complete retrieval pipeline combining:

`Dense Embeddings` → `Semantic Retrieval` → `Cross-Encoder Reranking` → `Vector Store`

Also includes TF-IDF as a classical baseline, KMeans topic discovery, UMAP/PCA embedding visualization, persistent ChromaDB storage, and **Precision@K** evaluation.

**Stack:** `Python` `Sentence Transformers` `BERT` `ChromaDB` `CrossEncoder` `KMeans` `UMAP` `PCA`

---

<div align="center">

### 📩 Spam / Ham / Smishing Detector
**NLP Multi-Class Classification**

</div>

A 3-class NLP classifier with adversarial stress-testing samples, multiple algorithm comparisons, model evaluation, and serialization of the best-performing models.

**Stack:** `Python` `TF-IDF` `Sentence Transformers` `scikit-learn`
